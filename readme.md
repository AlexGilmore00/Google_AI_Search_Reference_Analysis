# Google AI Search Mode Reference Analysis

## Overview
This project aims to analyse Google's AI overview's referencing paterns (specifically focusing on UK staycation holiday booking) to see if there are any biases towards certain sources over others. It will gather reference data from the Google AI overview section (gathered with SerpAPI) returned from a wide array of prompts that vary from the location they were sent from, the location they ask about, the context given, and how the query was asked. This data is then formatted in a way as to make it easy to perform analysis on

## User Manuel
### Fist steps
Firstly and most importantly, you must create a `.env` file in the route directory of the repository. This is where you will add your SerpAPI API key under this format:
`SERP_API_KEY=\<your API key\>`

To get an API key, you must create an account at [serpapi.com](https://serpapi.com/) Then navigate to your profile page. This program is made to work with the SerpAPI free subscription though can be upscaled to work with higher tier subscriptions

From there, open the `main.py` file and run `tests.test_connection()` to test your API key is working. If the call is succesfu;, it will print your remaining credits

### Generating the data
To generate the data, navigate to the `main.py` file and run `gather_data.gather_data()`. This fucntion also takes two parameters:
1. A string as a parameter if you would like to change the filepath and file name used for outputting the data. This data will be output on csv format so it is recommended to use a `.csv` file. 
2. A bool used to determine whether to call `SerpAPI.prompter.retrieve_ai_overview_references()` with verbose doc active or not. verbose doc records the entire json reponse for the AI Overview section generated and returned by SerpAPI for each individual query in `SerpAPI/Verbose_Output/`

As previously mentioned, the data generated will be in csv format following this header:
|prompt_id|position|domain|title|full_link|full_query|full_send_location|
|:----|:----|:----|:----|:----|:----|:----|

Each row in the csv will represent a single reference within a prompt containing this information:
1. prompt_id - The id of the prompt that was used when this reference was generated
2. position - The position withing the generated responce that the reference was generated in reference to all other references within that response
3. domain - The domain that was cited
4. title - The title of the page that was cited
5. full_link - The full URL that was cited
6. full_query - The full query used
7. full_send_location - The full location the questy was sent from

### Structuring the data
Once you have generated the data, you may want to structure it in a way that makes it easier for analysis. To do this, navigate to `main.py` and run `structure_data.group_by_prompt()`. This file takes in two parameters:
1. in_file - A string. This determines what file the method will read from to prodice the structured output. This should be a file created by `Project.gather_data.gather_data()`
1. out_file - A string. This determines in which file the new structured data will be outputted to. The output will be in csv format so it is recommended to use a `.csv` file

`structure_data.group_by_prompt()` groups every prompt by these criteria:
- prompt style
- prompt context
- where the prompt was asking about
- where the prompt was sent from
It then creates a running tally for each group tallying how many times each unique domain was referenced in responses generated by a prompt within that prompt group. From there it looks through every row in the raw data csv (remember, each row is an individual reference), takes the domain for that row and the prompt id, breaks down the prompt id to determine which groups it fits into, then increments the tally counter for that specific domian within the relevant groups. The full list of prompt groups are as follows:
- `all_prompts` (This shows data for every prompt used)
- `what_style_prompts` (This shows data for prompts asking 'what are some good holidays')
- `how_style_prompts` (This shows data for prompts asking 'how to book a holiday')
- `with_context_prompts` (This shows data for prompts with added context on what holiday they'd like)
- `without_context_prompts` (This shows data for prompts with no extra context)
- `about_scotland` (this shows data about prompts asking about holidays in scottland)
- `about_england` (this shows data about prompts asking about holidays in england)
- `about_local` (this shows data about prompts asking about holidays local to where the prompt was sent from)
- `from_<location>` (these show data about prompts sent from \<location\>)

After that, the results will be outputted to the inputted file in csv format in this style

|group_id|\[domain1\]|\[domain2\]|\[domain3\]|...|
|--------:|--------:|--------:|--------:|--------:|
|all_groups|\[# of refs\]|\[# of refs\]|\[# of refs\]|...|
|...|...|...|...|...|

Each row will represent a prompt group, the first column of every row will represent the id of that prompt group, and every other column will represent a unique domain and gow many times it was references within that prompt group
